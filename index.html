About these numbers. Current HOT locked is read from the Raindex vault, and incoming deposits are counted using verified Lock events. The released total uses total locks minus the latest vault balance; the claim component is an accounting estimate after subtracting AdminWithdraw events, not a verified list of claim transactions. Data read from Etherscan is not an atomic snapshot, so in-flight blocks can briefly cause differences. These Ethereum events cannot confirm mirrored issuance, collection or HoloFuel swaps on Unyt. The percentage is based on the Ethereum ERC-20 on-chain totalSupply, not an externally estimated circulating supply. Unique locking wallets count distinct sender addresses recorded in Lock events (possibly smart contracts), not people or verified Unyt accounts. New wallets means first Lock event within the last 7 days.
